# Feasibility Toolbox — GitHub Pages package

This folder contains the static GitHub Pages version of the Feasibility Toolbox.

## Publish at `https://guo7501.github.io`

1. Create a public GitHub repository named `guo7501.github.io`.
2. Upload **all files and folders from this package** to the repository root. Keep `index.html`, `app.mjs`, `style.css`, and the `assets` folder at the top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub finishes deploying, open `https://guo7501.github.io`.

If the repository uses another account name, the repository must be named `<username>.github.io`, and the address will be `https://<username>.github.io`.

## Notes

- The calculator runs entirely in the browser.
- User edits remain in the current browser session and are not stored on a server.
- Google Fonts are loaded from the internet; the site remains functional if they are unavailable.
